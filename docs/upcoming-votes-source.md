# Upcoming votes — ingestion source

Research dated 2026-05-08. Confirmed via WebFetch.

## Source URLs

**Calendar index page** (server-rendered HTML):

- `https://www.congreso.es/es/calendario-de-sesiones-plenarias`
- Links the PDF for the **next** upcoming pleno
- Renders 6-month table grids: plenary days carry `class="day pleno"`,
  non-working `class="day"`

**Per-session orden del día PDF** (deterministic pattern):

- `https://www.congreso.es/backoffice_doc/atp/orden_dia/pleno_<NNN>_<DDMMYYYY>.pdf`
- Examples confirmed live:
  - `pleno_178_07052026.pdf` (next pleno)
  - `pleno_175_28042026.pdf` (last)
- Filename encodes session number + date deterministically.

**Annual planning** (long-horizon backstop only — week-granular,
non-binding):

- `https://www.congreso.es/webpublica/ficherosportal/CALENDARIOPLENOS<YYYY>.pdf`

## Confirmed dead ends

- `/agenda` — generic events calendar (foros, jornadas), no orden del día
- `/orden-del-dia`, `/sesiones-plenarias`, `/calendario`, `/cem/agenda`,
  `/cem/calendario` — all 404
- OpenData feeds at `/es/opendata/{diputados,votaciones,iniciativas,intervenciones}`
  — do **not** include agenda data

## Format

PDF generated by Word, ~7 pages, fully extractable text (verified with
`pypdf` — clean structured layout, no OCR needed).

## Extractable fields

Verified from `pleno_175_28042026.pdf`:

- Session number (`Sesión nº175`) and date (`Martes, 28 de abril de 2026`)
- Per-day sub-headers (`MARTES, 28 DE ABRIL`, `A las 15 horas`)
- Section headings:
  - `I. Toma en consideración de Proposiciones de Ley`
  - `II. Convalidación o derogación de Reales Decretos-leyes`
  - `III. Proposiciones no de Ley`
  - `IV. Mociones consecuencia de interpelaciones urgentes`
  - `V. Preguntas` (con destinatario: PRESIDENTE DEL GOBIERNO, MINISTRO DE
    HACIENDA, etc.)
  - `VI. Interpelaciones urgentes`
  - `VII. ...`
  - `VIII. Debates de totalidad de iniciativas de reforma constitucional`
- Per item: order number, proposing group (`Del Grupo Parlamentario VOX`),
  title, BOCG reference, expediente number `(Núm. expte NNN/NNNNNN)` —
  same regex `_EXPTE_RE` already in
  `backend/app/ingest/congreso/client.py` line 319 works directly
- Notes section at top capturing modifications (e.g. "ha acordado la
  modificación del orden del día en el sentido de excluir el punto 29")

## robots.txt

`robots.txt` does **not** restrict `/backoffice_doc/`,
`/calendario-de-sesiones-plenarias`, `/agenda`, or `/es/opendata/*`. URL
pattern `pleno_<NNN>_<DDMMYYYY>.pdf` has been stable across 2024–2026.

## Concrete ingest plan

Add:

- `backend/app/ingest/congreso/agenda.py` — PDF parser
- `CongresoClient.fetch_calendar_html()` and `fetch_orden_del_dia_pdf(url)`
  in `backend/app/ingest/congreso/client.py`
- Models `ScheduledSession` and `ScheduledAgendaItem`:
  - `ScheduledSession`: `session_number`, `date`, `pdf_url`, `fetched_at`,
    `status` enum `{scheduled, modified, cancelled, completed}`
  - `ScheduledAgendaItem`: FK to session, `position`, `section`, `kind`,
    `proposing_group`, `subject`, `official_id` nullable FK to
    `initiatives`, `target_minister` nullable
- Alembic migration
- RQ job `import_upcoming_agenda`:
  - Daily at 08:00 Europe/Madrid
  - Extra run Mondays at 14:00 (the Mesa typically publishes / tweaks the
    week's pleno on Friday / Monday)
  - Each run: GET calendar HTML → extract PDF URL + all `day pleno` cells
    → for the PDF link, download, parse with `pypdf`, upsert by
    `(session_number, date)`
  - Edits / deletions handled by a `last_seen_at` field plus a status flip
    when an item disappears between runs
- Wire into `app/api/votes` with a `?status=scheduled` filter and a
  `/api/v1/sessions/upcoming` endpoint for the home-page widget

## Edge cases

- "Scheduled" really means **next pleno's orden del día**. The calendar
  page only ever exposes one PDF link (the most imminent). Beyond that,
  `class="day pleno"` cells signal *expected* plenary days for the
  semester but without orden — surface those as `status=planned` (date
  only, no items) to avoid overpromising.
- Sessions get postponed: BOCG publishes Mesa modifications (e.g. "la
  semana del 14 al 16 de mayo no se celebre sesión plenaria"). The
  `class="day pleno"` cell is updated when this happens; our daily diff
  catches removals → flip status to `cancelled`.
- Orden del día itself is amended (last verified PDF excluded item 29
  explicitly). Re-parse on every run; track `version_seen_at` per item;
  surface a "modificado" badge in the UI.
- Annual planning calendar `CALENDARIOPLENOS<YYYY>.pdf` is the long-horizon
  backstop but is week-granular and binding only loosely — do **not**
  display its dates as confirmed plenos; use it only to bootstrap empty
  months.
- Ministerial questions (section V) are noisy political theatre — we
  should ingest them but in the UI default to collapsing them under a
  "Preguntas al Gobierno (N)" disclosure to avoid drowning genuine
  legislative items.
